3. Raw-read QC — FastQC 0.12.1

FastQC was run separately on both raw paired-end FASTQ files. The supplied reports confirm FastQC v0.12.1. R1 showed warnings for per-base sequence content, per-sequence GC content and adapter content; R2 showed additional failures in per-base quality, per-tile quality and per-base sequence content. These flags motivated the subsequent filtering step.

# Raw read quality assessment
cd /home/ali/for_tezis
mkdir -p fastqc_results

fastqc \
  SRR2584863_1.fastq.gz \
  SRR2584863_2.fastq.gz \
  -o fastqc_results

4. Read filtering and trimming — fastp 1.1.0

The recorded fastp run started with 3.106518 million reads (465.977700 Mb) and retained 2.602652 million reads (83.780361%). Mean read length decreased from 150 bp to 142 bp. Q20 increased from 89.165974% to 96.208397%, and Q30 from 81.633512% to 89.136192%.

# Paired-end quality filtering and adapter processing
fastp \
  -i SRR2584863_1.fastq.gz \
  -I SRR2584863_2.fastq.gz \
  -o clean_R1.fastq.gz \
  -O clean_R2.fastq.gz \
  -h fastp_report.html \
  -j fastp_report.json \
  -w 8

5. Genome assembly — SPAdes 4.2.0

The cleaned paired-end reads were assembled with SPAdes using --careful, 8 threads and 24 GB RAM. The command below preserves the recorded absolute paths.

# SPAdes 4.2.0 — bacterial genome assembly
/home/ali/miniforge3/envs/bacteria_assembly_env/bin/spades.py \
  -1 /home/ali/for_tezis/fastp/clean_R1.fastq.gz \
  -2 /home/ali/for_tezis/fastp/clean_R2.fastq.gz \
  -o /home/ali/for_tezis/fastp/assembly_result \
  --careful \
  --threads 8 \
  --memory 24
Output used for downstream assessment: /home/ali/for_tezis/fastp/assembly_result/contigs.fasta. The BUSCO JSON records a copied/alternate path (/home/ali/for_tezis/assembly_result/contigs.fasta); the sequence filename is the same.

7. Completeness and contamination — CheckM2 1.1.0

CheckM2 was run on Galaxy Europe. The recorded result was 100.0% completeness and 0.11% contamination, with a coding density of approximately 88% and 4,328 predicted coding sequences. These values support a highly complete draft with very low estimated contamination.

9. Coverage — recorded estimate

Using the post-filtering total of 372,036,560 bases and the 4,576,410-bp assembly, the estimated average sequencing depth is approximately 81.3×:

# Estimated average depth = filtered bases / assembly size
372036560 / 4576410 = 81.32x
This is an arithmetic estimate from total filtered bases. It is not a per-base mapping depth profile. A true depth distribution requires mapping the reads to the assembly and calculating depth with a mapper/samtools workflow.
